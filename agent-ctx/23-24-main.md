## Task Info
- **Task ID**: 23-24
- **Agent**: main

## Summary
Implemented two features for the Sellora e-commerce dashboard:

### Feature #23: Voice Message Transcription
- Customers can record voice notes that are transcribed by AI and inserted into the chat input
- Uses z-ai-web-dev-sdk ASR as primary, Groq Whisper as fallback
- VoiceRecorder component with compact (button) and full (waveform) modes
- Integrated into CopilotPanel and conversations chat input

### Feature #24: Image Recognition
- Customers can upload photos and AI matches them to the product catalog
- Uses z-ai-web-dev-sdk VLM as primary, Gemini Vision and NVIDIA Vision as fallbacks
- ImageUploader component with compact (popup) and full (drag & drop) modes
- Auto-recognition on incoming image messages in conversations
- Product matching with confidence scores and inline results
